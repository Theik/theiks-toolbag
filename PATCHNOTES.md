# Patch notes

## 1.2.0

- Added Diggable Terrain. Empty space on a Scene or Level fills with packed earth. GMs excavate it from Destruction Mode. Regions can force earth over floors, keep holes empty, or change the textures.
- Scenes with 200 or more destroyable walls and tiles only show destruction markers within 20 grid spaces of the cursor.
- Visible Light controls now appear next to a controlled Token. Light Toggle Mode shows every fixture.

## 1.1.1

- Hidden usable Tiles no longer show a lever marker or accept use.

## 1.1.0

- Added Usable Tiles with image-based states, lever controls, player proximity checks, script events, settings, and Macro API support.
- Integrated Usable Tiles with Breakable Terrain, including shared configuration and reliable image precedence while damaged.
- Destroyed Wall rubble now stops at physical Walls and closed doors.
- Updated the README with clearer documentation and a Usable Tiles demo.

## 1.0.0

The first release of Theik's Toolbag.

- Added breakable Walls and Terrain, including rubble, damage states, wall splitting, blocking, repairs, and collapsing platforms.
- Added Visible Lights that GMs and nearby players can operate from the Canvas.
- Added Level Tools for moving Tokens between Scene Levels and elevations.
- Added script behaviors, feature settings, destruction controls, and a Macro API.
